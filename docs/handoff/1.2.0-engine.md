## WPF integration

- Use `GamePlan.Step` for the effective quality step. Use `GamePlan.Recommendation` for the loaded quality estimate and `GamePlan.SettingAdvice` for individual setting suggestions, assumptions, and fallback. `GamePlan.Evidence` includes the available source text and links.
- Load locations on demand with `OptimizerSession.InspectPlan(game, cancellationToken: token)`. The inspection is synchronous and can involve local file reads. Show `SettingsCandidates` with confidence and source evidence. `SettingsDiscovery.Diagnostics` explains missing or ambiguous leads. Shorten paths for display with `PathDisplay.Short`.
- Keep capture results and guide observation scopes visible. A benchmark is evidence about the paired captures. A published guide describes the build or period cited in its source.
- A batch draft is a preview for confirmation. Each drafted value comes from an observed after snapshot at one explicit quality step. Empty slots keep the setting. Single-game `--save` stores inactive drafts under the user rules draft directory.
